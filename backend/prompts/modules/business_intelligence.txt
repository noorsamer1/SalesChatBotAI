**🏢 BUSINESS CONTEXT - KUWAIT FOOD DISTRIBUTION**

**MARKET OVERVIEW:**
- **Business Model**: B2B Food & Beverage Distribution in Kuwait
- **Key Sectors**: HORECA (Hotels/Restaurants), Cooperatives, Key Accounts, Traditional Trade
- **Product Portfolio**: International food brands (McCain, Alpro, Quest) + Local brands
- **Geographic Coverage**: Kuwait nationwide through 9 distribution centers

**📍 WAREHOUSE/BRANCH MAPPING (Use for stakeholder-friendly names):**
- **WH1** → "Main Distribution Center"
- **WH2** → "Central Kuwait Branch"  
- **WH4** → "Kuwait City Branch"
- **KPC-MAIN** → "KPC Main Warehouse"
- **CTE** → "Central Trade Exchange"
- **BUR** → "Burgan Branch"
- **SRWH** → "South Region Warehouse"
- **GRVWH** → "Greater Region Warehouse"
- **W5N** → "West 5N Branch"

**🚨 BRANCH QUERIES - STAKEHOLDER-FRIENDLY FORMAT:**
For any branch/warehouse analysis, use this SQL pattern:
```sql
-- Use CASE statement to show meaningful branch names
SELECT 
  CASE 
    WHEN warehouse_name = 'WH1' THEN 'Main Distribution Center'
    WHEN warehouse_name = 'WH2' THEN 'Central Kuwait Branch'
    WHEN warehouse_name = 'WH4' THEN 'Kuwait City Branch'
    WHEN warehouse_name = 'KPC-MAIN' THEN 'KPC Main Warehouse'
    WHEN warehouse_name = 'CTE' THEN 'Central Trade Exchange'
    WHEN warehouse_name = 'BUR' THEN 'Burgan Branch'
    WHEN warehouse_name = 'SRWH' THEN 'South Region Warehouse'
    WHEN warehouse_name = 'GRVWH' THEN 'Greater Region Warehouse'
    WHEN warehouse_name = 'W5N' THEN 'West 5N Branch'
    ELSE warehouse_name
  END as branch_name,
  ROUND(SUM(sales_value), 3) as total_sales
FROM sales_data 
WHERE [CONDITIONS]
GROUP BY warehouse_name 
ORDER BY total_sales DESC
```

**📊 KEY BUSINESS DIVISIONS:**
1. **HORECA** (35% of business) - Hotels, Restaurants, Cafes
2. **COOPS** (30%) - Cooperative societies (major retail channel in Kuwait)  
3. **KEY ACCOUNTS** (20%) - Major corporate/retail clients
4. **TRADITIONAL-TRADE** (10%) - Independent retailers
5. **PASTRY-BAKERY** (4%) - Specialized bakery channel
6. **OTHERS/OTH-DIFF** (1%) - Miscellaneous channels

**💰 FINANCIAL STRUCTURE:**
- **Average Transaction**: ~26 KWD (Non-promo), ~36 KWD (Promotional)
- **Profit Margins**: 16.6% (Regular), 27.4% (Promotional)
- **Promotional Strategy**: 8.9% of transactions, higher value/margin
- **Returns Rate**: 19% of transactions (high due to food perishability)
- **FOC Strategy**: 4.4% - Free samples and promotional giveaways

**🎯 ADVANCED ANALYTICS PATTERNS:**

**Performance Rankings:**
- Always include growth rates when comparing periods
- Show both volume (qty) and value (sales_value) metrics
- Include profit margins for business decision-making
- Rank by total sales unless specified otherwise

**Multi-Group Query Patterns:**
```sql
-- Division Performance with Profitability
SELECT division_name, 
       ROUND(SUM(sales_value), 3) as total_sales,
       ROUND(SUM(sales_prof), 3) as total_profit,
       ROUND(AVG(sales_prof/NULLIF(sales_value,0)*100), 1) as profit_margin_pct,
       COUNT(DISTINCT customer_name_e) as unique_customers
FROM sales_data 
WHERE yy = 2025 
GROUP BY division_name 
ORDER BY total_sales DESC
```

**Table Sizing Rules:**
- Top 10 for products/customers (unless specified)
- Top 5 for high-level summaries (divisions, warehouses)
- Top 20+ for detailed operational queries
- Always show percentage contribution when relevant

**PROMOTIONAL CAMPAIGNS ANALYSIS TEMPLATE:**
```sql
SELECT 
  CASE WHEN promo = 'Y' THEN 'Promotional' ELSE 'Non-Promotional' END AS promo_status,
  COUNT(*) as transactions,
  ROUND(SUM(sales_value), 3) as total_sales,
  ROUND(AVG(sales_value), 2) as avg_transaction_value,
  ROUND(SUM(sales_prof), 3) as total_profit,
  ROUND(AVG(sales_prof/NULLIF(sales_value,0)*100), 1) as profit_margin_pct
FROM sales_data 
WHERE yy = 2025
GROUP BY promo
ORDER BY total_sales DESC
```

**CRITICAL:**
- ALWAYS use promo = 'Y' and promo = 'N' (not tran_type = 'Promo')
- Include avg_transaction_value for promotional analysis  
- Use 2025 as default year for promotional campaigns unless specified
- Show both absolute values and percentages for business insights
